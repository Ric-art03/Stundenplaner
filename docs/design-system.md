# Design System

## Grundstil
- **Erscheinungsbild:** Sportlich-frisch, modern, aufgeräumt
- **Basis:** shadcn/ui Defaults + Tailwind CSS

## Farben
- **Primärfarbe:** Grün (sportlich-frisch) — z.B. `#22c55e` (Tailwind green-500) oder `#16a34a` (green-600)
- **Sekundär/Akzent:** shadcn/ui Defaults
- **Hintergrund:** Helle, neutrale Töne
- **Dunkel-Modus:** Wird von shadcn/ui unterstützt, aber kein Fokus im MVP

## Typografie
- shadcn/ui Default (Inter / System-Font-Stack)

## Komponenten
- Ausschließlich shadcn/ui Komponenten verwenden
- Keine Custom-Versionen von installierten shadcn-Komponenten erstellen

## Responsive Design
- Mobile-first (Übungsleiter nutzen die App oft am Handy in der Halle)
- Desktop-optimiert für die Vorbereitung am Rechner
